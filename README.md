# MISUMI 상품 카드 (V2)

미리 만들어 둔 상품 카드를 골라서 Outlook 메일에 붙여넣는 웹 페이지입니다.

- 상품명(한글)·형번·초성으로 검색, 구분별 필터, 여러 장 선택 후 한 번에 복사
- 경제형 상품도 포함하지만 경제형에 한정하지 않습니다 (전체 상품 397개)

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 화면 (이 파일 하나로 동작) |
| `data/catalog.json` | 상품 목록 (이름·형번·가격·납기·링크·사진 주소) |
| `images1/`, `images2/`, `images3/` | 상품 사진 (파일명 = 시리즈코드). GitHub 웹 업로드가 1회 100개 파일 제한이라 3개 폴더로 나눔 |

이 프로젝트는 이전 프로젝트(ProductCard)와 별개이며, 이전 프로젝트의 파일을 수정하지 않습니다.
